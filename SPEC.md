# Spec

A single rotating cube rendered in a full-screen canvas.

## Requirements

- One cube, centered in the scene, rotating continuously on its own.
- The canvas fills the entire viewport (no scrollbars, no margins) and resizes with the window.
- The user can rotate the view with the mouse via drei's `OrbitControls` (drag to orbit).
- Built with React Three Fiber and drei.

## Out of scope

- Multiple objects, textures, UI overlays, physics.
